# Falu's Universal Modular Tool System (UMTS)

The STL files in this folder are **not my work**. They were designed by **Falu Mendy Vergara** ([@FaluMendy on MakerWorld](https://makerworld.com/en/models/2029113-modular-system-for-a1-p1-x1-series)) and are copied here unchanged from his model "Modular System For A1, P1, & X1 Series", so that this private project has everything needed to print the pencil holder in one place.

| File | What it is |
|---|---|
| `Head-Mount-V1-Series X and Series P.stl` | Clips onto the P1S / X1 toolhead and holds a tool guide in three clip rings |
| `Upper Spring System/Spring Module D9 5mm.stl` | Printed spring that sits on the guide and grips pens up to about 8.9 mm |
| `Upper Spring System/Spring Module D11 5 mm.stl` | The same for pens up to about 10.9 mm |
| `Tool Guide Modules/Guide Stabilo D 8 55mm.stl` | His guide for a Stabilo fineliner; the outside of `../out/pencil_guide.stl` was measured from it |
